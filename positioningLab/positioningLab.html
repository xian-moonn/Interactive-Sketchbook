positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection: I think fixed positioning made the most sense to me because the result is very obvious. When I fixed the footer, I could immediately see that it stayed in the same place while I scrolled. Relative positioning moves an element relative to where it normally would be, but it still leaves its original space on the page. Absolute positioning removes the element from the normal flow completely, and it positions itself relative to the nearest positioned parent container (or the whole page). It stays at the bottom right all the time, no matter where you scroll and resize the window. The z-index it’s like a layer system in photoshop. When you set the number to 0, it means putting the element at the bottom. When you set the number to a higher number, it will be on top of 0 and might be covering the element below.
