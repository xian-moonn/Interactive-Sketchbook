I determined the elements that should be in the flex container when you want to control and put your item in a row or column. I think the #content is the parent container and the #lyrics and #album became the flex items. Before applying the display: flex, it stacked vertically like normal block elements. After applying display: flex, it changed into rows. Changing the widths controlled how much space each column took. Margin and padding changed the spacing around and inside the columns. If the widths were too large, the layout would wrap or overflow. At first I was so confused about the font, because I saw in the css it is connected to the right place. Then when I looked at the go live page, the font is the default font and not the font selected in css. I was really confused about this part, but then I tried to retype the path and realized that I needed to add the ../ at the start. So this is how I solved the problem.
