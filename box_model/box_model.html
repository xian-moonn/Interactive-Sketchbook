Reflection: Adding a background color helps me understand the difference between margin and padding. When I changed the padding the background color changed the size as well. When I changed the margin, it added spaces outside of the box. One thing I noticed was that borders and backgrounds only changed the element’s own box, not one big group box. Each tag has its own separate box. Padding and borders made elements take up much more room than I expected. Even a small change in padding could shift the whole layout and create extra scrolling. When I set the .blockTo paragraphs to inline, they stopped stacking and sat side by side. When I set links to block, they stacked vertically instead. Block elements take up a full line and start on a new line, so they stack on top of each other. Inline elements stay in the same line and only take up as much width as their content needs. When I renamed and moved the folder into my Interactive Sketchbook, it worked as usual. The page was just another page added to the sketchbook that could be accessed from the main navigation. The paths did not break because I kept the css folder and style.css in the same relative location. If a path had broken, I would check the link href, look for errors in the browser console, and make sure the file name and folder location matched exactly.
