Process Reflection

I started with editing the colors and font settings first. Then I started to adjust the page. I am having trouble with the page setting, I don't know how to make the body stick to the top and bottom like how the reference image is. I am also having trouble sticking the footer the same width as the body just like in the reference, I tried using margin and padding but none of them works. This part frustrated me a lot. The 3 images part, I have an issue with making them stay closer together, I have tried to use margin and padding for the images as well, it just doesn't work at all, it still has a big gap in between the images. The recent issues part, for the bullet points, in the reference image the space between each line, I tried padding and I don't think anything has changed. After that, I realized that I shouldn't change the margin and padding for the universal one so I just set them both to 0. And then I started to change the margin and padding for the sections. Finally, I think for now everything works well and it is as close as I can get to match the reference image.
