Heyaa! My name is Moon, and I'm from Hong Kong. I'm majoring in Visual Communication Design. I'm taking this class because it's required for my major, but also because I want to learn some new skills so that I can use them in my own creative work later on.

A little more about me: I'm a VTuber and I usually stream on Twitch. I also draw and take commissions for other VTubers sometimes. I mostly make chibi illustrations and emotes for them. My creative interests include character design and digital illustration.

Right now, I want to keep improving my understanding of HTML coding so that I can create my own page when I want to. I've always thought that creating a website was pretty hard. I used to think a website needed a big server to host it, so it never felt like something I could do myself. This class is slowly changing that. I'm learning that even small steps, like writing simple tags and linking images, can add up to something real. It's exciting to see a page come together, even if it's not perfect yet.
